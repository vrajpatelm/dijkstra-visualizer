Dijkstra's Algorithm — Presentation Guide

💡 What is Dijkstra's Algorithm?

An optimal greedy algorithm published by Edsger W. Dijkstra in 1959. It finds the single-source shortest paths to all reachable vertices in a weighted graph with non-negative edge weights.

⚡ How It Works (Step-by-Step)

  1. Initialize: Set dist[source] = 0, all others to ∞. Push (0, source) into a Min-Heap.
  2. Extract Min: Pop the unvisited node u with smallest known distance. Mark u as settled (finalized).
  3. Edge Relaxation: For each neighbor v of u, check:
    if dist[u] + weight(u, v) < dist[v]:
      dist[v] = dist[u] + weight(u, v)
      previous[v] = u
  4. Repeat: Continue until the target is popped or the queue is empty.

🔑 Key Properties

  • Greedy Choice: Always processes the closest unvisited node first.
  • Optimal Substructure: Sub-paths of shortest paths are themselves shortest.
  • No Negative Weights: Assumes once a node is settled, no shorter path can be found to it.

⏱️ Complexity

Time: O((V + E) log V) with binary min-heap.

Space: O(V) for distances, predecessors, and queue.

⚠️ Limitations

Negative weights break the algorithm. Use Bellman-Ford for graphs with negative edges. Dijkstra's is optimal for non-negative weighted graphs.
